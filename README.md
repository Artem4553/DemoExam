# WpfApp1 — приложение для работы с товарами

## Описание
Приложение разработано на C# с использованием WPF в среде Visual Studio.

## Основные возможности
- Авторизация пользователя.
- Работа с информацией о товарах.
- Отображение данных о товарах и их характеристик.

## Используемые технологии
- C#
- WPF
- XAML
- Visual Studio

## Запуск проекта
1. Скачайте или клонируйте репозиторий.
2. Откройте файл `WpfApp1.sln` в Visual Studio.
3. Восстановите необходимые зависимости, если потребуется.
4. Запустите приложение клавишей F5.

## Исходный код
Исходный код приложения находится в папке `WpfApp1`.
